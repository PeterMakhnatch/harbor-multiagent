# Register a native two-model team and both single-model controls

This study tests native wiring and what reaches each participant. It does not rank models. Previous Claude results use offline dispatch replays. This study instead runs 2 real stock Olam seats in each fresh trial, including an inventory actor whose submitted reports become the dispatch actor's live input. The actor backend is a host-side first-party subscription. Containers receive neither session credentials nor API keys.

**Fixed before collection:** 2 previously unused synthetic shipment seeds, 2003 and 2017. The condition is `reordered`, with 8 shipments per world. Run 4 teams per seed: `ss` (both last-arrival scripts), `ms` (model inventory and script dispatch), `sm` (script inventory and model dispatch), `mm` (both model). For seed 2003 use ss, ms, sm, mm; for 2017 reverse that order. Register exactly 8 native world attempts and at most 8 model generations (1 turn per live model seat). A failed earlier seat might prevent a later generation. No retries, replacements, provider changes, or stored choices. An invalid generation stays unmeasured. Run sequentially and avoid the hourly control window.

**Provider:** the authenticated first-party Claude Max CLI, attested `claude-sonnet-5-5` only. Each isolated command uses a fresh session, no tools, MCP, browser, project instructions or model fallback. Use the same bounded adapter as the prior methodological control. Set a $0.30 equivalent cap per generation ($2.40 maximum over all 8). No API key, paid Docker provider, or GPU. Provider estimates are not invoices. The collector reports missing cost as null, not zero. If the appropriate subscription or execution boundary cannot be established, do not generate.

**Evidence and readouts:** retain native UUID, role-specific received view digest, exact on-wire model view digest and bytes, accepted role submission digest, and served-model/usage evidence. Reconstruct both views and submissions from scored world data, excluding all system paths, credentials, unreleased inputs, free text, and model transcripts. Separately report native team scores, per-seat trial coverage, whether the reporter's accepted structured reports appear in dispatch's actual input, and local optimal/feasible decisions. Report unknown for missing generations, inputs or observations. Distinguish rejected attempts from bad model choices. Results from 2 worlds and a small number of stochastic generations cannot estimate a coordination advantage or supply training labels about an agent's reasoning.
