# Changing dispatch context without changing the actor

This study is **not** a continuation of the free native model pilot. That pilot has 4 native attempts with no measured model output. A separate diagnostic received HTTP 404 for the declared router and provider data policy. We keep that policy intact, do not retry that route, and suspend the hosted arm of the hourly canary. The local stock-oracle canary remains eligible in all 8 windows.

**Input:** use the two `reordered` dispatch observations from held-out arrival-policy panel A: seeds 1001 and 1003, each with 12 shipments. These role views were reconstructed from retained native evidence. They were not acknowledged by the original actor. Do not send unavailable truth, the inventory view, scenario seeds, existing decisions, private host paths, or operator instructions to the model.

**Intervention:** `raw` sends the chronological arrival sequence for each shipment. `highest_revision` retains only the report with the greatest explicit revision number for that shipment. Both use the same system instruction, role and output format. Compute byte lengths from canonical UTF-8 JSON and count input tokens only if the actual service reports them. No stochastic comparison is a causal estimate from these 2 worlds.

**Record before generating:** use the operator's already authenticated first-party Claude Max CLI and configured model `claude-sonnet-5-5`. Use no tools or MCP servers, no session reuse, no provider fallback, and no API-key environment. Admit only an explicitly attested served model. Try 4 independent commands: seed 1001 `raw`, then `highest_revision`; seed 1003 `highest_revision`, then `raw`. No retries. Bound the equivalent provider estimate to at most $0.30 for each command when supported by this CLI. Do not start if a required bound or subscription cannot be established. A refusal or malformed answer is not a score of zero. A CLI provider cost estimate is not a subscription charge.

Score the actual returned choices locally against the original native worlds. Report complete / attempted / planned, per-seed optimal and feasible counts, and paired decision changes. Keep the deterministic last-arrival actor as a separate control. This experiment concerns **a dispatch-only replay**, not a new native Harbor trial, two new model agents, or the effect of a prompt on the original trials. A client acknowledging an input hash confirms a protocol step, not that a model understood the input.
