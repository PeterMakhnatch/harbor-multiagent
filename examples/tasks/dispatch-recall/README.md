# Dispatch Recall

Two teammates share a warehouse. The loader stages a crate. The depot sees where the crate is now and can send a report. The loader commits to one bay. The team earns a point only if the crate is in that bay.

The world, not a timer or an agent, determines whether the loader receives the report before commitment, after commitment or not at all. An absent physical commitment is distinct from choosing the wrong bay. Neither message quality nor a judge model determines the reward.

Use the [operator guide](../../seatlab/dispatch_recall/README.md) to rehearse the task, check the physical decision and prepare a study. Keep that guide and all verifier records outside participant contexts. Give each participant only its own role instruction.
