# Holdout: when does a blind listener look coordinated?

The first 3 seeds did not produce a case in which an always-landmark-0 listener matched its partner's real target. Register a separate consecutive seed cohort, without inspecting goals first. This tests when equal native behavior fails to distinguish an informed policy from one that ignores a present channel. It does not test language understanding.

**Before looking:** use seeds 101 through 112 inclusive, in ascending order. Never inspect a seed to decide whether to keep it. Cross all 12 seeds with the 5 unchanged teams from the [initial registration](protocol.md). This yields 60 named native trials and 48 comparisons against `plain-plain`. Do not pool the initial 15 trials into the holdout or replace a missing attempt. No model, no parameter search, no changes to the game, rewards, movement rule, communication encoding, or 20-cycle horizon. Use the official pinned MPE2 and PettingZoo versions and the identical trusted seat executables.

**Before native collection:** run the independent official engine and separately implemented actors on all fixed seeds. Freeze an allowlisted forecast containing the seed's actual target, all 5 predicted terminal returns, and the first changed listener action, first changed physical observation, and number of different listener actions for each of the 4 comparisons. Publish the forecast hash and bytes on the personal fork before native trials. Do not change that forecast after seeing a native result. These simulated forecasts are not native measurements.

**Primary unit:** one world seed. For each seed, derive the target from the native `plain` speaker's first accepted symbol. Record how many native blind policies match every accepted action of the informed listener, separately when the hidden target is 0 and when it is not. A listener can choose identical moves for multiple steps while pursuing a different goal. If a cohort has no examples in a group, report that count; never refill it. Compare all 20 actions, not just the completion reward, and report exact numerator and denominator. Do not treat a missing flow or a missing native value as a failed or successful prediction.

**Controls:** `rotate-rotate` should preserve every listener action and physical feature despite changing the first speaker symbol. Mismatched conventions need not have worse returns on every map. Report how often the 2 cross conventions do better, tie, or do worse than the baseline. Do not make a population, language, agency, or causal claim. Report any case where a different policy matches movement, target, or payoff, rather than using score as a proxy for information use.

**Independent check:** compare native recorded 2-role decisions, observations, returns and termination flags against the official simulator. Forecast agreement uses exact world step and strict integer equality; return tolerance 1e-6. Report each trial's native UUID. Count each native 2-player team return only once. Preserve the registered denominator on host or scheduling failures. Keep cases, traces and rendered reports data-only. Do not publish logs, input paths, Docker credentials or participant environments.

**Collection:** independent cells can run on up to 3 local Docker slots. Each may claim a cell once. Share no agent state between cells. Leave the hourly control its own local runtime. Stop before additional cost or destructive cleanup. This is a deterministic workload; no metered external model is needed.
